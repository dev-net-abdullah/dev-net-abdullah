## About

I'm the CTO of **Kreate Vision**, based in Pakistan. I lead engineering for our product suite and for the US home-service businesses we work with. I build and run production systems across the whole stack: marketing sites that rank, multi-tenant SaaS platforms, internal tools that handle payroll and invoicing, native iOS apps, and AI integrations that connect it all.

- **CTO at Kreate Vision**: I own the technical direction, architecture and delivery for the KV products and client platforms
- **Previously Lead Developer & Technical Architect at Extreme Freelancing Trainings (XFT)**, where I built XIMS/Evira and Extreme IMS, ran client engagements and mentored intern cohorts
- **BSCS student at NUML Islamabad** (expected 2027)

## Things I've Built

| Project | What it is |
|---|---|
| **KV Staff** | Workforce platform for time tracking, activity, pay, Wise payouts and client invoicing |
| **KV client portal + MCP server** | Multi-site SEO, leads, ads and analytics portal for agency clients, exposed to AI assistants through an MCP server |
| **Contractor field app** | Astro web app + SwiftUI iOS app for contractors: estimates, invoices and job scheduling from the field |
| **XIMS / Evira** | Intern management platform built around a git-style workflow, used to run real intern cohorts (XFT) |
| **Extreme IMS** | Multi-tenant institute management SaaS for coaching centers (XFT) |
| **GFunnel** | Multi-tenant SEO and analytics platform with client tenants and integrations |

**Up next:** a single sign-on portal for the KV product suite: one login and one-click access to every app, built as an OIDC provider on Better Auth.
